mcp-probe — auditing the tools AI agents call

Everyone is shipping MCP servers. Almost nobody is testing them. mcp-probe connects to any server, discovers its tools, generates adversarial calls from each tool's own schema — wrong types, missing fields, 100,000-character strings, injection-shaped payloads — and scores how it holds up. I used it to audit 13 public servers including Anthropic's, Google's, Microsoft's and MongoDB's, and privately disclosed real input-validation gaps in two.

Then I measured the ecosystem properly. PyPI carries ~18,000 packages with "mcp" in the name, so I drew a seeded random sample of 300 rather than hand-picking, and reported the rate with Wilson confidence intervals. Metadata alone said 86% were exposed — but metadata is not evidence, so I installed a random subsample into fresh virtualenvs and ran them. That second stage cleared three packages that looked broken and start fine. Publishing the first number would have been confidently wrong about three maintainers.
